# Домашнее задание 3

Ledger хранит транзакции и бюджеты категорий в памяти. При превышении бюджета
транзакция отклоняется. Бюджеты добавляются и обновляются через `SetBudget`,
а `LoadBudgets` читает их из JSON.

Требуется Go 1.22 или новее. Запуск из корня репозитория:

```sh
cd hw-3/ledger
go run .
```

Аргументы не требуются. Программа обновляет начальные бюджеты из `budgets.json`
в текущей папке: массив объектов с полями `category` (категория) и `limit` (лимит).
Чтобы изменить бюджеты, отредактируйте этот файл.

В примере проверяются расходы в пределах бюджета, ровно до лимита, сверх лимита,
категория без бюджета и нулевая сумма. С исходным `budgets.json` сохраняются четыре
транзакции, две отклоняются с сообщениями об ошибках. Итоговый список выводится
в консоль. После завершения данные не сохраняются.

# Домашнее задание 4

Ledger проверяет транзакции и бюджеты через интерфейс `Validatable` и методы
`Validate()`. Суммы и лимиты должны быть положительными, категории — непустыми,
даты транзакций — в формате `ГГГГ-ММ-ДД`. Неверные данные не сохраняются.

Требуется Go 1.22 или новее. Запуск из корня репозитория:

```sh
cd hw-4/ledger
go run .
```

Аргументы не требуются. Бюджеты загружаются из `budgets.json` в текущей папке:
массив объектов с полями `category` (категория) и `limit` (лимит).

Программа демонстрирует `CheckValid` для `Transaction` и `Budget`, затем
добавление транзакций с проверкой данных и лимитов бюджета. С исходным JSON
сохраняются четыре транзакции, пять отклоняются. Ошибки и итоговый список
выводятся в консоль. Все данные хранятся только в памяти во время запуска.

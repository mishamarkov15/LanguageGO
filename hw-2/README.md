# Домашнее задание 2

Два отдельных Go-модуля: `gateway` — HTTP-сервер, `ledger` — добавление
и вывод транзакций из памяти. Ledger назначает ID автоматически и отклоняет
транзакции с нулевой суммой.

Требуется Go 1.22 или новее. Команды запуска выполняются из корня репозитория.

## Gateway

```sh
cd hw-2/gateway
go run .
```

В другом терминале проверьте ответ сервера:

```sh
curl -i http://localhost:8080/ping
```

Ожидается статус `200 OK` и тело ответа `pong`. Для остановки сервера нажмите `Ctrl+C`.

## Ledger

В отдельном терминале:

```sh
cd hw-2/ledger
go run .
```

Программа выводит `Ledger service started`, добавляет три примера транзакций,
печатает их список и завершается. Данные хранятся только в памяти во время запуска.
Аргументы командной строки не требуются.

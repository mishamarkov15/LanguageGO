# Запуск

Требуется Go 1.22 или новее. Из корня репозитория:

```sh
cd hw-1
go run . аргумент1 "аргумент с пробелами"
```

После `go run .` можно передать любое количество произвольных строк. Программа
просто выводит их на экран: специальных команд или флагов у неё нет.
Аргументы разделяются пробелами; текст с пробелами нужно заключить в кавычки,
чтобы он считался одним аргументом.

В примере выше передаются два аргумента: `аргумент1` и `аргумент с пробелами`.
Аргументы можно не указывать — тогда программа выведет пустой список `[]`.
